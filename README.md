# 📱 Educação Financeira na Prática

Aplicativo gamificado (estilo Duolingo) para aprendizado de finanças pessoais.

---

## 📁 Estrutura do Projeto

```text
Financas/
├── index.html                 # Ponto de entrada padrão da aplicação
│
├── css/
│   └── style.css              # Animações, scrollbars e estilos de botões
│
└── js/
    ├── data.js                # Base de dados (níveis, tópicos teóricos e perguntas do quiz)
    ├── state.js               # Estado global da aplicação, pontuação e persistência
    ├── ui.js                  # Renderização das telas (Trilha, Caderno, Teoria e Modal)
    ├── quiz.js                # Mecânica do jogo (validação de resposta, pontuação, streak)
    └── app.js                 # Inicialização da aplicação e roteamento (navigate)
```

---

## 🚀 Como Executar

Abra o arquivo `index.html` no seu navegador favorito!
